# 쪼물랩 (Jjomul Lab)

12~40개월 아이와 부모가 함께하는 **소근육 놀이 구독 서비스**예요.
구독자는 비밀번호로 들어와 **자기 아이 연령 구간 버전**의 놀이를 보고, A4 1장으로 인쇄해요.

> 브랜드명 "쪼물랩"은 가칭이에요. 확정되면 `src/render/html.mjs`의 `BRAND`만 바꾸면 돼요.

## 빠른 시작

```bash
npm install
npm run validate                    # 콘텐츠 규칙 검사
npm run check                       # 모든 카드 × 연령 버전이 A4 1장에 들어가는지 검사
npm run preview                     # + 미리보기 PNG (output/previews/) — 서랍 썸네일·인스타 소재
ADMIN_PASSWORD=비밀번호 npm run dev  # http://localhost:3000 (어드민: /admin)
npm test
```

고객에게는 **HTML로만** 보여 줘요. PDF 파일은 만들지 않아요(유출될 파일이 생기지 않게).

## 폴더 구조

```
content/cards/c001.yaml …   콘텐츠 1개 = 파일 1개 (콘텐츠 서랍)
content/art/*.svg           오리지널 도안
content/sets/default.yaml   요일별 배치 (구독자는 셋을 받아요)
design/tokens.css           색·폰트·여백 (카테고리별 포인트 컬러)
collect.config.yaml         아이놀이 수집기 설정
src/content  src/render     콘텐츠 규칙 · 인쇄 시트/화면 가이드
src/app                     앱 본체 (Web 표준 API만 → Cloudflare로 옮길 수 있어요)
src/server.mjs              Node 서버 (로컬·VPS)
src/collect                 아이놀이 수집기
```

## 콘텐츠

한 콘텐츠에 **12~24개월 / 24~40개월 두 버전**이 들어가요. 상태가 올라갈수록 필요한 내용이 늘어요.

| 상태 | 필요한 것 |
|---|---|
| `idea` 아이디어 | 제목 · 카테고리 |
| `draft` 초안 | 버전 1개 이상 |
| `review` 검수 · `published` 발행 | 두 버전 모두 + 서랍 필드 (손 동작, 재료, 계절, 장소, 뒷정리, 준비 시간) |

구독자에게는 **`published` 콘텐츠만** 보여요. 예시는 `content/cards/c023.yaml`이에요.

버전마다 `print`로 **A4 1장 레이아웃**을 골라요.
- `art`: 도안만 (가이드는 화면으로)
- `art+guide`: 도안 + 핵심 가이드
- `guide`: 가이드만 (도안이 없는 놀이)

`validate`가 막는 것
- 효과 약속·임상 표현: 치료, 치유, 교정, 진단, 효과, 보장, 향상 (발달·훈련·학습은 주의 표시)
- 위험 재료: 구슬, 단추, 동전, 가위, 칼, 작은 솜공, 콩, 풍선
- 보호자 동반 문장이 없는 안전 체크

먹는 재료가 있으면 알레르기 안내를 넣으라고 알려 줘요.

## 서비스 흐름

1. **어드민 › 구독자**에서 등록해요 (구독 / 체험, 기간, 아이 생년월, 유입 경로, 추천인).
   - 구독자 ID(`S-0001`)와 **비밀번호 1개**가 발급돼요. 보낼 메시지까지 만들어져요.
   - 비밀번호는 해시만 저장하고, 재발급하면 이전 비밀번호와 열린 화면이 모두 끊겨요.
2. 구독 시작일부터 **평일마다 놀이가 하나씩** 열려요(00시, 한국 시간). 셋의 순서대로 열리고, 주말은 쉬어요.
3. 연령 구간은 생년월로 자동 계산돼요 (24개월이 되면 자동으로 바뀌어요). 어드민에서 고정할 수도 있어요.
4. 콘텐츠 페이지에서 할 수 있는 것
   - 화면 가이드 + **인쇄하기** (OS 기본 인쇄창, A4 1장)
   - **또 하고 싶어요** / **우리 아이와는 안 맞았어요**
     - 안 맞았을 때 이유: 어려워요 · 쉬워요 · 재료 구하기가 어려워요 · 아이가 관심 없어요 · 시간이 짧아요 · 안 해봤어요 · 의견 보내기
   - 의견 보내기, 우리 아이 작품 보내기 (+ 홍보 사용 동의)
5. 내 놀이 화면에서 볼 수 있는 것
   - 오늘의 놀이 (주말엔 쉬어요 안내)
   - 준비물 미리 보기: 평일엔 이번 주, 주말엔 다음 주 재료 (놀이 제목은 그날까지 비밀)
   - 지난 놀이 어땠어요? (평가 안 한 놀이)
   - 만료 3일 전 안내
6. 모든 반응은 **서버에 저장**되고, 슬랙에는 알림만 가요.
   - 형식: `[평점] S-0001 · c023 · 2026-10-23 · A점`

### 보호 수준 (솔직한 한계)

- 하는 것
  - 원본 파일을 제공하지 않아요.
  - 만료·정지·재발급을 서버가 매 요청마다 확인해요.
  - 화면 워터마크(구독자 ID)를 깔고, 인쇄물 하단에 `ID S-0001`을 작게 넣어요.
  - 우클릭·저장 단축키를 막고, 로그인 5회 실패 시 10분 잠가요.
- 못 하는 것
  - 인쇄창의 "PDF로 저장"을 막을 수 없어요(OS 기능이에요).
  - 스크린샷을 완전히 막을 수 없어요.
  - 그래서 구독자 ID가 남게 해서 유출되면 출처를 알 수 있게 했어요.

## 어드민 (`/admin`)

| 탭 | 내용 |
|---|---|
| 콘텐츠 서랍 | **메모장**(아이디어 바로 적기) + 전체 콘텐츠 모아보기(상태·카테고리·계절 필터), 상세에서 두 버전 인쇄 미리보기·반응 |
| 구독자 | 등록·수정(기간 연장, 정지), 비밀번호 재발급, 구독자별 셋과 반응 분석(카테고리별 또/안 맞음, 해봤어요 비율), 작품·의견 |
| 콘텐츠 셋 | 셋을 주차 × 요일 표로 보기 (지금은 모두 기본 셋) |
| 수집함 | 유튜브·인스타에서 모은 아이디어 (제목·개요·원본 링크) → 보관 / 제외 / 콘텐츠화(c000 연결) |
| 받은 소식 | 최근 평가·의견·작품 |

콘텐츠와 셋은 YAML 파일에서 고치고, 어드민은 모아보는 곳이에요.

## 아이놀이 수집기

```bash
npm run collect     # 또는 어드민 › 수집함 › 지금 수집하기
```

- `collect.config.yaml`에 유튜브 채널(`@핸들`, 채널 주소, `UC…`)과 인스타 해시태그를 적어요.
- **유튜브**
  - `YOUTUBE_API_KEY`가 있으면 공식 Data API를 써요(무료 할당량 안에서 충분해요).
  - 없으면 채널 RSS를 써요. RSS는 유튜브 쪽에서 간헐적으로 404·500 오류가 나서 API 키를 권해요.
- **인스타그램**
  - 공식 Instagram Graph API의 해시태그 검색만 써요(크롤링은 이용약관 위반이라 쓰지 않아요).
  - 필요한 것: 비즈니스·크리에이터 계정, 페이스북 페이지 연결, 메타 앱, `IG_USER_ID`·`IG_ACCESS_TOKEN`.
  - 해시태그는 7일에 30개까지 조회할 수 있어요.
- 원본 문구·이미지는 저장하지 않고 **링크와 짧은 요약만** 남겨요. 아이디어만 참고하고 문구·그림은 새로 만들어요.

## 환경변수

| 이름 | 용도 |
|---|---|
| `ADMIN_PASSWORD` | 어드민 비밀번호 (없으면 어드민이 꺼져 있어요) |
| `SLACK_WEBHOOK_URL` | 슬랙 알림 (없으면 터미널에 출력) |
| `BASE_URL` | 안내 메시지·슬랙에 들어갈 서비스 주소 |
| `DATA_DIR` | 데이터 폴더 (기본 `viewer-data/`, git에 올라가지 않아요) |
| `TRUST_PROXY=1` · `COOKIE_SECURE=1` | 프록시·HTTPS 뒤에서 실행할 때 |
| `YOUTUBE_API_KEY` · `IG_USER_ID` · `IG_ACCESS_TOKEN` · `IG_GRAPH_VERSION` | 수집기 |

## 배포 (추천: Cloudflare 무료 플랜)

`src/app`은 Web 표준 API만 써서 Cloudflare Workers에서 그대로 돌아가요. 남은 작업은 세 가지예요.
1. `store-file.mjs`와 같은 모양의 D1(데이터) · R2(작품 사진) 저장소를 만들어요.
2. 콘텐츠를 JSON으로 묶어요.
3. 글꼴을 정적 파일로 올려요.

수집기는 Cron Trigger로 매일 자동 실행할 수 있어요.
